# JS Intro

## Running the project

1. **Install Live Server in VS Code**
   - Open VS Code and click the **Extensions** icon in the left sidebar (or press `Ctrl+Shift+X` / `Cmd+Shift+X` on Mac).
   - Search for **Live Server** (by Ritwick Dey) and click **Install**.

2. **Open the project**
   - In VS Code, go to **File → Open Folder** and select this project folder.... or you can just open it from your terminal by traversing to it via cd, then typing "code ."

3. **Launch the page**
   - In the Explorer sidebar, right-click `intro.html` and choose **Open with Live Server**.
   - Your browser will open the page, and it reloads automatically each time you save a file.
